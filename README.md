### Automation Framework


## Introduction 

This document provides an overview of how to set up and run the SpecFlow Automation Framework for testing web APIs.


## Prerequisites

1. .NET Core 3.1 or later
2. Visual Studio 2022


## Tools

* C#
* NUnit
* Specflow
* RestSharp

## Installation

1. Clone the project from git repository
2. Open the solution in Visual studio 2022
3. Restore the NuGet packages by right-clicking on the solution and selecting **Restore NuGet Packages**.

## Running the Tests

1. Open the **Test Explorer** window in Visual Studio.

2. To select **Test Explorer**  first left click on **Test** menu on top left side then select **Test Explorer** from options

3. Right-click on the solution and select **Build Solution**.

4. Right-click on the solution and select **Run Tests**.
